# PDF font

Noto Sans Regular static TrueType font from the official Noto fonts repository:
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Distributed under the SIL Open Font License in OFL.txt. The static font is intentional: the previously tested variable font produced incomplete glyph rendering when subset for PDF export. Verification includes PDF text extraction and a rendered page with the rupee glyph.
