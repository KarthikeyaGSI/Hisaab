# Complete project-card demo

The local-only fixture in `src/lib/complete-card-demo.ts` demonstrates a project card with a sanction, contract, three payment instalments, gross/deduction/net accounting, a fictional recipient profile, and a reported completion record.

Every project, person, organisation, amount, identifier, date, location, receipt and contact detail in the fixture is invented. Contact values use the reserved `.invalid` domain and placeholder phone/address data. The coordinates are only for map framing and do not identify a real project site. The displayed Mapbox image is map context, not an asset photograph. The recipient portrait is intentionally a labelled placeholder; no real person's image is used.

The demo is selected only when the URL contains `demo=complete` and the fixed demo work ID. It is never inserted into the public work catalogue, API, coverage counts, funding aggregates or publication database. Keep the `DEMO ONLY · FICTIONAL RECORD` banner visible in clean filming mode. Do not cite or publish the fixture as evidence.

Open it at `/?work=demo-complete-school-card&state=KA&explore=1&demo=complete` or from Content Mode → Director → Card shots → Open complete demo card.
